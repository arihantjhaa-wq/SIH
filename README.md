# Kheti Seedha (AgriDirect)

Direct farm-to-consumer and farm-to-business marketplace.

## Project Structure

- `frontend/` - React + Vite frontend application
- `marketplace-backend/` - Node.js + Express + MongoDB backend API
- `pricing-engine-api/` - Fast-API Pricing Engine service

## Quick Start

### 1. Backend Setup
```bash
cd marketplace-backend
cp .env.example .env
# Edit .env and fill in required secrets
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
